# 🧾 Simple Registration and Login Console App

A simple console-based **Registration & Login system** written in **Python**.  
The project demonstrates basic concepts of:
- user input validation
- regular expressions (regex)
- authentication logic
- console interaction

This project is suitable for **beginners** who want to practice Python fundamentals.

## 🛠️ Technologies Used

- **Python 3+**
- `re` (Regular Expressions)
- Standard Python libraries only

---

## 📂 Project Structure

```

reg_log/
│
├── main.py          # Entry point of the application
├── validators.py    # Input validation logic (regex)
├── users.py         # User data handling
├── README.md        # Project documentation

```

*(Structure may vary slightly depending on implementation)*


## 🚀 How to Run the Project

### 1️⃣ Clone the repository
```bash
git clone https://github.com/yeemaae/reg_log.git
````

### 2️⃣ Navigate to the project folder

```bash
cd reg_log
```

### 3️⃣ Make sure Python 3+ is installed

Check version:

```bash
python --version
```

or

```bash
python3 --version
```

### 4️⃣ Run the application

```bash
python main.py
```
